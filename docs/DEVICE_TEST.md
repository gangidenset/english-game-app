# スマートフォン実機確認（Phase 13）

## 1. 自動確認（ブラウザの端末エミュレーション）

Playwright（Chromium）の端末エミュレーションで、各サイズのホーム画面・バトル画面を確認した結果です。

| 端末 | 画面サイズ | 横スクロール | バトルの4択が1画面に収まるか | 備考 |
| --- | --- | --- | --- | --- |
| iPhone SE | 320×568 | なし | ✅（背の低い端末用レイアウト） | ホームは縦スクロール |
| iPhone 15 Pro Max | 430×739 | なし | ✅ | |
| Pixel 7 | 412×839 | なし | ✅ | |
| Galaxy S9+ | 320×658 | なし | ✅ | |
| iPad Mini | 768×1024 | なし | ✅ | タブレット用に中央寄せ |
| Galaxy Tab S4 | 712×1138 | なし | ✅ | |
| PC | 1280×800 | なし | ✅ | 幅 640px の中央表示 |
| iPhone 12（横向き） | 750×340 | なし | スクロールが必要 | PWA は縦向き固定 |

確認して直したこと：

- 背の低い端末で 4 つ目の選択肢と解説が画面外に出る → 余白・文字サイズを詰めるレイアウトを追加
- 不正解のときの解説が画面外に出る → 自動でスクロールして表示
- タブレットでホーム画面の中央に大きな空白ができる → 縦方向の中央寄せに変更

> エミュレーションは画面サイズの確認です。タッチ操作の感触、効果音、バイブレーション、
> 「ホーム画面に追加」は、下のチェックリストで**実機**を使って確認してください。

## 2. 実機チェックリスト

GitHub Pages の URL（`https://gangidenset.github.io/english-game-app/`）をスマホで開いて確認します。
公開前に確認したい場合は、PC で `npm run dev` を実行し、同じ Wi-Fi のスマホから
`http://<PCのIPアドレス>:5173/` を開きます（Service Worker は https または localhost でしか動かないため、
PWA の確認は GitHub Pages 上で行います）。

### 共通

- [ ] ホーム画面のレベル・XP・連続学習日数・ミッションが表示される
- [ ] バトル開始 → 4択をタップできる（押し間違えにくい大きさか）
- [ ] 制限時間が減り、0 になると「時間切れ」になる
- [ ] 不正解でライフが減り、3 回でゲームオーバーになる
- [ ] 連続正解でコンボが表示される
- [ ] 結果画面のランク・XP・レベルアップ表示
- [ ] 復習画面 → 再挑戦
- [ ] アプリを閉じて開き直しても XP・記録が残っている
- [ ] 効果音が鳴る／設定で OFF にできる
- [ ] 文字が小さすぎない・はみ出さない
- [ ] バトル中に通知などで別アプリに切り替えて戻っても、時間が進みすぎない

### iPhone（Safari）

- [ ] 共有ボタン → 「ホーム画面に追加」でアイコンが追加される
- [ ] ホーム画面のアイコンから起動すると、アドレスバーなしで全画面表示になる
- [ ] ノッチ・ホームバーにボタンが重ならない
- [ ] 機内モードにしても起動・バトルができる（一度オンラインで開いた後）
- [ ] マナーモード（消音スイッチ）中は効果音が鳴らない（iOS の仕様）

### Android（Chrome）

- [ ] メニュー → 「アプリをインストール」でインストールできる
- [ ] 起動時にスプラッシュ画面（アイコン＋背景色）が表示される
- [ ] 不正解・ゲームオーバー時にバイブレーションする
- [ ] 機内モードでも起動・バトルができる

### iPad / Android タブレット

- [ ] 縦向き・横向きで表示が崩れない
- [ ] ホーム画面に追加して起動できる
